Không biến game thành giao diện quản lý khô khan.

Hãy giữ linh hồn:

“Mỗi bông hoa là một lá thư. Mỗi mùa hoa là một ký ức.”

Thiết kế toàn bộ game theo concept Cozy Garden + Postal + Autumn + Fairy Tale, đồng bộ với website “Bưu Điện Của Những Nỗi Nhớ”.
